Desktop

Preview limitations

Internet required. The Android APK is a website client for Android 8+ and is not a Google Play release. No native push notifications, background tasks or offline editing. Use Browser for unsupported links. Preview builds use development signing; future builds may require uninstalling the old preview before installing the new one. Uninstalling clears the app’s local login, not your server workspace.
